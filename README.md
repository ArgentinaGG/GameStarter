# GameStarter

GameStarter is a reusable foundation for Unity that provides a base structure and some useful scripts to help you get started with your game development projects.

# Installation

1. Start a new Unity project.
2. Package Manager > Package Manager > Add package from git URL: 
	`https://github.com/ArgentinaGG/GameStarter.git?path=/Packages/gg.argentina.gamestarter`
3. Done! A menu will appear in the top bar called "GameStarter" with information to get started.
